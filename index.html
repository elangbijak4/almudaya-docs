Beranda Dokumentasi GitHub

Infrastruktur Blockchain Modular untuk Edukasi & Pengujian

Jalankan jaringan lokal Almudaya langsung dari terminal Anda. Sepenuhnya kompatibel dengan MetaMask, dilengkapi 20 akun pre-funded, dan siap untuk mendemonstrasikan Decentralized Applications (DApp).

Baca Dokumentasi Source Code (GitHub)
npx almudaya-blockchain

🖥️ Web-based Dashboard

Termasuk antarmuka GUI ala Ganache yang otomatis menyala. Pantau saldo, log, blok, dan transaksi secara real-time dari browser Anda.

📦 Tanpa Instalasi Rumit

Tidak perlu setup berjam-jam. Cukup jalankan satu perintah npx dan server RPC lokal Anda langsung menyala di port 8545.

🦊 MetaMask Ready

Mendukung protokol Ethereum RPC standar (seperti eth_sendRawTransaction) sehingga Anda bisa langsung menghubungkannya ke MetaMask.

💰 20 Akun Demo

Sama seperti Ganache, Almudaya langsung menyediakan 20 dompet HD yang masing-masing berisi 10.000 saldo token demo siap pakai.

⚙️ Custom AVM

Dilengkapi mesin virtual (Almudaya Virtual Machine) yang dirancang khusus dengan opcode yang mudah dipelajari untuk mahasiswa.

📂 Storage Modular

Penyimpanan state otomatis tersimpan di folder kerja Anda (Current Working Directory), menjaga kebersihan sistem global komputer Anda.

🚀 Open Source

Kode didistribusikan secara bebas di bawah Lisensi MIT. Anda bebas membongkar, memodifikasi, dan menggunakan kodenya untuk keperluan apapun.
