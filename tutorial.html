Panduan Pelatihan Dosen & Mahasiswa

Panduan komprehensif ini ditujukan bagi dosen atau instruktur yang ingin menggunakan Almudaya Blockchain sebagai media pengajaran kelas atau demonstrasi pembuatan Decentralized Application (DApp).

Catatan: Platform ini adalah purwarupa blockchain modular yang dibangun dengan Node.js. Ia memiliki Virtual Machine miliknya sendiri (bukan EVM), namun dilengkapi dengan lapisan RPC yang 100% kompatibel dengan MetaMask.

1. Persiapan & Menjalankan Node Lokal

Syarat utama: Komputer/laptop dosen dan mahasiswa harus sudah terinstal Node.js (versi 18 ke atas).

Untuk menjalankan blockchain lokal, tidak perlu mengunduh installer. Buka terminal (Command Prompt) dan ketik:

npx almudaya-blockchain

Saat dijalankan pertama kali, terminal akan menampilkan informasi penting:

  • Alamat RPC Server: http://127.0.0.1:8545/rpc
  • Chain ID: 0x539 (1337 dalam desimal)
  • Mnemonic (Words Phrase): 12 kata rahasia yang bisa diimpor ke MetaMask.
  • 20 Akun Demo: Masing-masing berisi 10.000 saldo (beserta Private Key-nya).

2. Mengakses Dashboard GUI

Almudaya dilengkapi dengan antarmuka grafis (GUI) bawaan yang elegan bergaya Ganache untuk mempermudah instruktur dalam memantau jaringan tanpa harus menggunakan baris perintah (CLI) yang rumit.

Untuk mengaksesnya:

  1. Pastikan Anda sudah menjalankan perintah `npx almudaya-blockchain` di terminal.
  2. Buka browser (Chrome/Edge/Firefox).
  3. Kunjungi alamat: http://127.0.0.1:8545

Di dalam dashboard tersebut, Anda bisa melihat saldo secara real-time, riwayat transaksi, blok yang ditambang, serta menyalin Private Key untuk disambungkan ke dompet Anda.

3. Menghubungkan ke MetaMask

Agar mahasiswa dapat berinteraksi dengan blockchain ini melalui antarmuka web, mereka perlu mengonfigurasi dompet MetaMask di browser mereka.

  1. Buka ekstensi MetaMask.
  2. Klik pemilih jaringan (Network Selector) di bagian atas dan pilih "Add a network manually".
  3. Masukkan data berikut:
    • Network Name: Almudaya Localnet
    • New RPC URL: http://127.0.0.1:8545/rpc
    • Chain ID: 1337
    • Currency Symbol: AGV
  4. Simpan. Kini MetaMask Anda telah terhubung ke Almudaya Blockchain!

Anda bisa mengimpor salah satu Private Key dari terminal untuk melihat saldo 10.000 AGV Anda muncul di dompet.

4. Bahasa Smart Contract (AVM)

Berbeda dengan Ethereum yang menggunakan Solidity, Almudaya menggunakan instruksi perakitan (Assembly-like) sederhana yang dirancang khusus untuk keperluan edukasi dasar blockchain.

Contoh kontrak sederhana untuk membagi donasi ke 2 alamat:

// Kontrak Splitter
PUSH 0xAddressPenerima1
PUSH 50
TRANSFER
PUSH 0xAddressPenerima2
PUSH 50
TRANSFER
HALT
Penting: Karena ini adalah Custom AVM, Anda tidak bisa mendeploy kontrak menggunakan Web3.js standar (seperti pada Ethereum). Anda harus menggunakan metode RPC deployContract dan callContract yang disediakan oleh API lokal Almudaya.

5. Demonstrasi Interaksi DApp (Frontend)

Berikut adalah contoh kode HTML/JavaScript statis yang dapat diberikan kepada mahasiswa untuk mendemonstrasikan interaksi Web3 murni menggunakan Fetch API (tanpa library tambahan).

<!DOCTYPE html>
<html>
<head>
    <title>Demo DApp Almudaya</title>
</head>
<body>
    <h1>Cek Saldo Akun</h1>
    <input type="text" id="addressInput" placeholder="Masukkan Address 0x..." style="width: 300px;">
    <button onclick="cekSaldo()">Cek Saldo</button>
    
    <h2 id="hasilSaldo">Saldo: 0</h2>

    <script>
        async function cekSaldo() {
            const address = document.getElementById('addressInput').value;
            
            // Format JSON-RPC standar Ethereum
            const payload = {
                jsonrpc: "2.0",
                method: "eth_getBalance",
                params: [address, "latest"],
                id: 1
            };

            try {
                const response = await fetch('http://127.0.0.1:8545/rpc', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify(payload)
                });
                
                const data = await response.json();
                
                // Konversi dari Hex (Wei) ke Desimal
                const saldoHex = data.result;
                const saldoDecimal = parseInt(saldoHex, 16);
                
                document.getElementById('hasilSaldo').innerText = "Saldo: " + saldoDecimal + " AGV";
            } catch (error) {
                alert("Gagal koneksi ke RPC Server Almudaya!");
                console.error(error);
            }
        }
    </script>
</body>
</html>
